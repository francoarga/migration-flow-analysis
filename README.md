# Migration Data Analysis

Data analysis project focused on migration flows and Argentine representation offices around the world using SQL and Python.

## Description

This project analyzes migration flows between countries and explores relationships between migration patterns and Argentine representation offices worldwide.

The analysis includes:
- data cleaning,
- SQL-based transformations,
- exploratory data analysis,
- migration flow calculations,
- regional aggregation,
- report generation,
- data visualization.

---

## Technologies

- Python
- Pandas
- SQL
- Matplotlib
- Seaborn
- inline_sql

---

## Main Features

- Data cleaning and preprocessing
- SQL joins across multiple datasets
- Migration flow analysis
- Regional statistics
- Automatic report export
- Data visualization with charts and boxplots
